# 🚀 VC Scout AI

An AI-powered startup discovery platform that helps users identify promising startups and open-source opportunities across different sectors. The application analyzes GitHub repositories and market signals to generate AI-driven investment insights using Google Gemini.

---

## ✨ Features

- ✅ AI-powered Startup Analysis
- ✅ Sector-based Startup Search
- ✅ Opportunity Scoring
- ✅ Risk Assessment
- ✅ Investment Score Generation
- ✅ GitHub Repository Analysis
- ✅ Startup Ranking
- ✅ Interactive Dashboard
- ✅ Modern Responsive UI

# 🚀 How It Works

1. Enter a startup sector (FinTech, AI, Healthcare, etc.)
2. The application searches for relevant startup repositories.
3. GitHub and market information is collected.
4. Google Gemini analyzes each opportunity.
5. AI generates:
   - Opportunity Score
   - Market Score
   - Unicorn Potential
   - Risk Level
6. Results are displayed in an interactive dashboard.
